# 交互式数据分析系统

这是一个基于 Flask、Pandas、Scikit-learn 和 Plotly 的课程实验型交互式数据分析系统。系统支持 CSV / Excel 数据上传、数据预览、数据集说明、数据清洗、统计分析、KMeans 聚类、聚类质量评价、交互式可视化和结果导出，适合作为 Python 数据分析系统课程大作业演示项目。

## 一、功能模块

| 模块 | 主要功能 |
|---|---|
| 数据上传模块 | 支持 CSV、XLSX、XLS 文件上传，限制上传大小为 10MB，并进行文件名安全处理和格式校验 |
| 数据预览模块 | 展示文件名、数据行列数、字段列表和前 20 行数据 |
| 数据集说明模块 | 展示字段类型、缺失值、重复行、字段示例值；识别天气数据后显示常见字段解释 |
| 数据清洗模块 | 支持缺失值处理、重复值删除、异常值检测、字段类型转换、天气数据专用规则和清洗前后对比 |
| 数据分析模块 | 提供基础统计分析、KMeans 聚类、轮廓系数、肘部法 K 值选择和 PCA 二维聚类可视化 |
| 数据可视化模块 | 支持折线图、柱状图、饼图、散点图、相关性热力图、直方图、箱线图、缺失值柱状图 |
| 结果导出模块 | 导出清洗后的 `cleaned_data.csv` 和分析后的 `analyzed_data.csv` |

系统新增了日期字段缺失值处理功能。由于 Date 字段在自动类型转换后属于 datetime 类型，原有数值型和类别型缺失值处理逻辑无法覆盖该类型，因此系统单独提供日期缺失处理策略，包括不处理、删除缺失行、前向/后向填充和连续日期自动补全。该功能能够避免清洗后 Date 字段仍保留缺失值，从而提高后续时间序列分析和趋势可视化的可靠性。

系统完整流程：

```text
数据上传 → 数据预览 → 数据集说明 → 数据清洗 → 数据分析 → 数据可视化 → 结果导出
```

## 六点五、前端交互设计说明

前端采用 Flask Jinja2 模板进行页面渲染，在此基础上引入少量原生 JavaScript 实现交互增强，包括表单提交状态提示、上传文件前端校验、导航栏当前页面高亮、图表类型动态表单切换、KMeans 特征字段全选/清空、日期缺失值策略提示、清洗选项联动、报告区块折叠展开和返回顶部等功能。该方案避免了完整前后端分离架构带来的复杂度，同时提升了系统易用性和交互体验。

## 八、当前不足与改进方向

当前系统主要面向课程实验和本地单机演示，暂未实现完善的用户登录和多用户数据隔离。系统使用全局变量暂存当前数据，单人本地演示可以接受；若部署到多用户环境，应引入 Flask session、数据库或用户隔离目录保存不同用户的数据集，避免数据互相覆盖。

## 九、常见问题

### 1. ModuleNotFoundError: No module named 'flask'

说明当前 Python 环境没有安装依赖，执行：

```bash
pip install -r requirements.txt
```

### 2. 上传文件后读取失败

请确认文件格式为 CSV、XLSX 或 XLS，且文件大小不超过 10MB。CSV 文件如果存在编码问题，系统会自动尝试 `utf-8-sig`、`utf-8`、`gbk`、`gb2312`、`latin1` 等常见编码。

### 3. 无法进行 KMeans 聚类

KMeans 至少需要 2 个有效数值字段，并且样本数量要足够。请先完成数据清洗，再选择多个数值字段进行分析。

### 4. 可视化页面没有图表

请先上传数据。如果当前数据没有合适字段，默认图表可能无法生成，可以尝试在自定义图表区域选择字段手动生成。
